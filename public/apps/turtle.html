Turtle

Papert’s turtle geometry, in Logo. Teach the turtle new words with TO … END, then watch it draw.

Ctrl + Enter runs the program. The turtle keeps its place between runs; start with CS for a clean page.

Commands

The turtle has a position and a heading. Headings are in degrees, clockwise from straight up. Watch the turned readout: any path that closes up and faces the way it started turns a whole number of times around, 360°, 720°, and so on. That is Papert’s Total Turtle Trip Theorem.

Moving

FD n, BK n
forward or back n steps
RT a, LT a
turn right or left a degrees
HOME
back to the middle, facing up
SETXY x y
go to a point
SETH a
face heading a
ARC a r
draw an arc of a degrees, radius r, around the turtle

Pen and page

PU, PD
pen up, pen down
SETPC c
pen color: 0–15, a name like "red, or [r g b] from 0 to 255
SETPENSIZE n
line width
SETBG c
page color
CS, CLEAN
clear and go home; clear only
HT, ST
hide or show the turtle
LABEL x
write text at the turtle
XCOR, YCOR, HEADING
where the turtle is
TOWARDS [x y]
heading that points at a spot
WAIT n
pause n sixtieths of a second

Procedures and control

TO name :in … END
define a procedure
REPEAT n [ … ]
repeat; REPCOUNT counts 1, 2, 3…
IF c [ … ]
run if c is true
IFELSE c [ … ] [ … ]
choose one
FOR [i 1 10 2] [ … ]
count with a variable
WHILE [c] [ … ]
loop while c is true
STOP, OUTPUT x
leave a procedure, or return a value
MAKE "n v, :n
set and read a variable
LOCAL "n
variable private to a procedure

Numbers, words, lists

+ - * / = < >
arithmetic and comparison
SUM, PRODUCT, QUOTIENT
also DIFFERENCE, REMAINDER, POWER
SQRT, SIN, COS, ARCTAN
trig works in degrees
RANDOM n
whole number from 0 to n − 1
LIST, SENTENCE, WORD
build lists and words
FIRST, BF, ITEM, COUNT
take them apart; PICK chooses one
PRINT x, SHOW x
write to the log below the page
